# Thread of Inquiry — Graduate Edition

A print-ready, editable topic-card deck for graduate research labs, inspired by the shared-scale conversation mechanism of *Ito / 命懸一線*.

Open `index.html` in a browser, or enable GitHub Pages from this repository's **Settings → Pages** panel.

## Use

1. Give each player a secret number from 0–100.
2. Reveal one topic card and choose either prompt.
3. Describe an example that fits the strength of your hidden number, without saying it.
4. Discuss and reveal players' numbers in the group’s predicted order.

Cards are standard poker-card proportion (2.5 × 3.5). Right-click a card to download a PNG; select several cards then choose **Download selected** for a batch.
